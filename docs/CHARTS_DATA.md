# Данные чартов из PDF

Исходники: `docs/GreenCharts2024_01-*.pdf` (8 страниц, на каждой несколько сеток).

Эталонные рэнжи: `src/entities/range/model/charts/*.json` — **один JSON на одну сетку** (например `rfi-utg`, `sb-vs-co`, `bb-vs-btn-25`).

## Обновление из PDF

```bash
npm run charts:render    # PDF → PNG в docs/rendered/
npm run charts:import    # сэмплинг цветов по scripts/chart-layouts.json
npm run charts:rfi       # RFI (стр. 4) из scripts/charts-green-data.mjs — точнее импорта
```

После правки `scripts/chart-layouts.json` (bbox сеток) снова запустите `charts:import`.

## Формат `solution`

Ключ — нотация руки (`AA`, `AKs`, `AKo`, …). Значение — массив id действий (1–3 для смешанной стратегии):

```json
"JTo": ["raise", "fold"],
"98o": ["fold"]
```

Цвета и подписи действий задаются в `actions` того же файла.

## Импорт с PDF

1. Откройте страницу PDF и сверьте **позицию**, **ситуацию** и **легенду цветов**.
2. Обновите `title`, `position`, `situation`, `actions` в соответствующем JSON.
3. Заполните `solution` по ячейкам сетки 13×13 (пустые ячейки можно не указывать — это фолд вне диапазона).
4. Для ячеек с двумя/тремя действиями укажите все id — в тренажёре они отображаются долями заливки.

Скопируйте PDF в репозиторий (например `docs/source-pdf/`), если нужна сверка в команде.

## Проверка

- **Проверить** сравнивает ваш ответ с `solution`.
- Оранжевая обводка — пропущена рука из эталона.
- Красная — неверный набор действий.
- Фиолетовая — лишняя отмеченная рука.
