# Данные чартов

Эталонные рэнжи хранятся в `src/entities/range/model/charts/*.json` — один JSON на одну
ситуацию/позицию (например `rfi-utg`, `sb-vs-co`, `bb-vs-btn-25`).

Заполнение и поддержка рэнжей выполняются вручную:

- через режим `Назначить` в интерфейсе тренажера;
- или прямым редактированием JSON-файлов в `src/entities/range/model/charts/`.

## Формат `solution`

Ключ — нотация руки (`AA`, `AKs`, `AKo`, …). Значение — массив id действий (1–3 для смешанной стратегии):

```json
"JTo": ["raise", "fold"],
"98o": ["fold"]
```

Цвета и подписи действий задаются в `actions` того же файла.

## Ручное обновление чартов

1. Обновите `title`, `position`, `situation`, `actions` в нужном JSON.
2. Заполните `solution` по ячейкам 13×13 (`AA`, `AKs`, `AKo`, ...).
3. Для смешанных стратегий указывайте несколько id действий.
4. Проверьте изменения в тренажере в режимах `Ренджи` и `Позиция`.

## Проверка

- **Проверить** сравнивает ваш ответ с `solution`.
- Оранжевая обводка — пропущена рука из эталона.
- Красная — неверный набор действий.
- Фиолетовая — лишняя отмеченная рука.
